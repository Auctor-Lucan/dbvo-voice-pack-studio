DBVO Voice Pack Studio - third-party components
================================================

The following components are included with DBVO Voice Pack Studio. Each keeps its own license.

ffmpeg (Tools\ffmpeg\ffmpeg.exe)
  FFmpeg, LGPL build from https://github.com/BtbN/FFmpeg-Builds (unmodified).
  License: GNU Lesser General Public License (version 3 for the included build) - see Tools\ffmpeg\LICENSE.txt.
  Source code: https://ffmpeg.org/download.html (exact build: see Tools\ffmpeg\SOURCE.txt).
  Used to convert audio (sample rate, format, loudness) and to decode .fuz / .xwm audio for playback.

7-Zip (Tools\7-Zip\7z.exe, 7z.dll)
  7-Zip 24.07, Copyright (C) 1999-2024 Igor Pavlov. https://www.7-zip.org/ (unmodified).
  License: GNU LGPL, with BSD 3-clause and unRAR license restrictions - see Tools\7-Zip\License.txt.
  Source code: https://www.7-zip.org/download.html
  Used to read .7z mod archives and to pack .7z FOMOD archives.

Whisper.net and whisper.cpp
  Whisper.net (https://github.com/sandrohanea/whisper.net), MIT License.
  whisper.cpp / ggml (https://github.com/ggml-org/whisper.cpp), MIT License.
  Whisper models are not included: they are downloaded on first use from Hugging Face (Whisper.net ggml models; OpenAI Whisper weights, MIT License).

K4os.Compression.LZ4 (https://github.com/MiloszKrajewski/K4os.Compression.LZ4), MIT License.
  Used to read Skyrim Special Edition BSA archives.

Microsoft .NET runtime (https://github.com/dotnet/runtime), MIT License.
Microsoft Edge WebView2 SDK (https://www.nuget.org/packages/Microsoft.Web.WebView2), Microsoft license (redistributable).
System.Security.Cryptography.ProtectedData (https://github.com/dotnet/runtime), MIT License.

FOMOD ModuleConfig.xsd, Copyright (c) 2017 Daniel Nunes, MIT License.

UESP reference data (NPC voice types, quoted dialogue, book authors)
  From UESP - The Unofficial Elder Scrolls Pages (https://en.uesp.net/), collected by Auctor Lucan.
  Licensed under Creative Commons Attribution-ShareAlike 2.5 (https://creativecommons.org/licenses/by-sa/2.5/).
