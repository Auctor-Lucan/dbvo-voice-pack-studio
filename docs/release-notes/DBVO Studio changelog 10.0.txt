Version 10.0.0
- New: DBReV packs (BETA TESTING). A voice pack's Pack format can now be DBReV, for Dragonborn ReVoiced, next to DBVO 1 (Legacy names) and DBVO 2.0. Files are named by plugin and FormID (Sound\DBReV\<pack ID>\<plugin>\dbrev_line_<FormID>.fuz), so a line whose text you changed still plays. Your other ★ kept takes become variations (1), (2)…, and Phase 3 installs the pack file DBReV needs. Supported with the consent of Raynor. Not played in game yet, so please report how it works.
- New: more voice engines (BETA TESTING). Fish Audio, Inworld, Cartesia, MiniMax and OpenAI-compatible (OpenAI, or a free server on your PC such as Chatterbox or Kokoro), next to ElevenLabs, OmniVoice and VoxCPM, in Phase 2, NPC Revoice, Voiced Books and Player Grunts. Keys go under Global Settings > Voice engines. They follow each engine's published API but haven't been tried with real accounts yet, so please report what works and what doesn't.
- Tags: every engine gets your [tags] the way it understands them, and the tag bar says how. Fish Audio and Inworld perform them, Cartesia and MiniMax turn a leading tag into an emotion, OpenAI-compatible engines get them as delivery instructions, and OmniVoice now performs [laughter] and [sigh] instead of dropping every tag.
- OmniVoice: works with the server DBReV Voice Pack Maker starts (port 8001), with its Language and Denoise settings. Check in Global Settings now says why a server shows offline (nothing answering, wrong port, or a web page instead of the server), and an address typed without http:// works.
- Check takes: a short first word followed by a pause (common with leading tags as context) was flagged as a burst at the start of the take. Fixed.
- Exports: the question about files from earlier exports only covers .fuz files in the final folder now. Old WAV and LIP files stay in the WAV + LIP folder as your archive of past takes.
- Undo: Ctrl+Z could only undo the page refreshing itself, never your own edits. Fixed.
- Edit take: leaving the page (mouse Back button, F1, Ctrl+K) asks before throwing away unsaved edits.
- Lots of smaller bug fixes, among them: a FOMOD build no longer overwrites edits you made while it ran, Delete buttons say why they can't delete instead of doing nothing, and a renamed mod category takes its mods along.
- User guide and PDF: new sections on voice engines, tags per engine and pack formats.
