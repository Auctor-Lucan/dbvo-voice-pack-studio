Version 12.0.0
- New: Variants. ★ Variants on the Phase 2 patch list opens a page per voice pack with every line of all its patches. A line with variants plays a different take each time you say it in game (Dragonborn Voice Over 2 and Dragonborn ReVoiced pick one at random). A line with the same file name in several patches counts once, so one set of variants covers every mod that has it.
- Suggested lists lines that are the same in two or more mods and have no variants yet, most used first. Click a line to hear its takes and star the ones that should play.
- Generate variants: tick lines and make one take per row of the Variant settings. Each row has its own Stability (Creative, Natural or Robust on eleven_v3/v4), Speed, a word merged into the prefix tag, and a seed (new each time, or fixed to repeat a reading). Sent as shows the exact text. Presets: Subtle, Lively, Moods, and your own.
- Prefix [tags] for variants, saved per voice pack, for example [British Extremely Baleful]. It is used only for variant takes made on the Variants page; your lines and other takes stay as they are.
- Context on / off shows how the prefix is sent: as context (not billed, a little weaker) or in the text (billed, full strength). It follows your Global Settings default until you change it on the Variants page.
- Takes made with Creative stability wait under Needs a look until you listen and star them, since they can drift out of the voice's accent.
- + Add a line: type a line as it appears in game. It shows the voice pack's file names, checks the line with the Phase 1 rules and suggests matching lines from your mods while you type.
- Variants Pack (Legacy names): every line with two or more ★ takes goes into one BSA, as DBVO 2 numbered files and DBReV name(1) files, with the empty light plugin that loads it and a list of the lines. Add to a FOMOD project puts it in a pre-ticked option that users can untick.
- Folder names that end in a period (a line like "Falkreath.") are kept in the BSA, where the game finds them. Windows can't create such folders, so the Variants Pack has to stay a BSA: unpacking it or repacking it with Cathedral Assets Optimizer breaks those variants.
- Reading plugins is faster and uses less memory: the parts of a plugin a task doesn't need (most of a large master) are skipped instead of loaded.
- DBVO Fix plugins are written next to the old file and then swapped in, so a crash or a full disk can't leave a cut-off plugin behind.
- NPC Revoice and the Voiced Books tool use less memory on large load orders.
- Fixed: a .fuz sub-folder typed as \Sound\DBVO\Vampira\ was treated as a folder elsewhere and replaced with Sound\DBVO\{packId}. It now counts as a folder inside the final folder.
