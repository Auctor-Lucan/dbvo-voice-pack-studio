Version 11.0.2
- Working indicator: when the app needs more than a moment (reading plugins, creating or opening a mod, saving, adding DBVO Patches), a "Working…" chip with a spinner shows at the top, with the seconds after a while, and the pointer shows it's busy. No more pauses that look like a hang.
- FOMOD build: the bar at the top shows at once, saying which step it's on (updating linked options, checking the installer, backing up the library, removing the previous staging folder, listing files), then counts files as they're staged and packed. Before, nothing showed for the first part of the build. While 7-Zip packs, the bar moves instead of sitting at 0.
- FOMOD builder: clicking ↑ (or ↓) again after a move moved the page, group or option back where it was, because the buttons still pointed at its old place. Delete and Duplicate right after a move could hit the wrong one too. Each click now acts on where it is now.
- New pages anywhere: + Page above and + Page below on a page, the button under the tree adds below the page you have open, and right-click a page in the tree for the same plus Move to the top / up / down / to the bottom and Delete. Right-click a group for + Group above, + Group below and + Option. A group has + Group below too.
- ⤒ and ⤓ move a page, group or option straight to the top or bottom. Pages and groups can also be dragged in the tree, groups onto another page.
- Order of the pages and of each page's groups can be set on the page (As listed, A–Z, Z–A). Many imported FOMODs are A–Z, where the installer sorts by name whatever the order in the tree; moving something in such a list now takes the order the installer showed and switches it to As listed.
- Saves go out in order, and Add DBVO Patches, Refresh linked and Build wait for a save in progress, so an older copy can't overwrite theirs.
- Import keeps the header image's showImage, showFade and height, alwaysInstall and installIfUsable written as 1 or 0, text in files declared as windows-1252 and the like, and no longer copies a foreign XML namespace into flags and conditions. An imported FOMOD that installs the DBVO JSON file deeper down (DragonbornVoiceOver\voice_packs\…, DBReV, or with / in the path) is recognised as already carrying it.
- Build: two sources outside the FOMOD root with the same name (two "Sound" folders of options named alike, two preview.png images) each keep their own files. Refresh linked no longer removes a DBVO Fix plugin of another mod you added to a linked option by hand.
- Simulate install shows pages, groups and options in the order the installer does. Add DBVO Patches with "Sort each group A–Z" only sorts the groups it added options to. Validate warns about a folder with no source (it installs the whole FOMOD root). Duplicate makes an unlinked copy.
